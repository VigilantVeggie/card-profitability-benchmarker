# Card Activation Benchmarker

An interactive calculator for card product managers and lifecycle marketers.
Model the revenue impact of improving card activation rates — instantly.

## What it does

- Input your current activation rate, cards issued, spend, and interchange
- Set a target activation rate
- See incremental revenue, ROI of an activation program, and benchmark comparison
  against industry averages — all in real time
